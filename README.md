# PRODIGY_DS_01

## Task 01 - Population Distribution Visualization

This project is completed as part of my Data Science Internship at Prodigy InfoTech.

## Objective

Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

## Dataset

The dataset used in this project is the World Bank population dataset provided by Prodigy InfoTech.

## Description

In this task, I created a bar chart to visualize the population distribution of selected countries for the year 2023.

## Tools and Libraries Used

- Python
- Pandas
- Matplotlib

## Steps Performed

1. Loaded the dataset using Pandas.
2. Cleaned unnecessary columns from the dataset.
3. Selected top/popular countries for visualization.
4. Created a bar chart using Matplotlib.
5. Saved the chart as an image.

## Output

The output chart shows the population distribution of selected countries in 2023.

## What I Learned

- How to load CSV data using Pandas
- How to clean and filter data
- How to create a bar chart using Matplotlib
- How to save visualizations as image files
